# Конспект JavaScript

## 1. Введение в JavaScript

### Что такое JavaScript
- JavaScript изначально придумали, чтобы «оживлять» веб-страницы.
- Программы на JS называют **скриптами**. Они встраиваются прямо в HTML и запускаются автоматически при загрузке страницы, без компиляции — исполняются как обычный текст.
- Несмотря на схожее название, JavaScript и Java — разные языки. Изначально JS назывался «LiveScript», но его переименовали, чтобы использовать популярность Java в маркетинговых целях.
- Со временем JS стал самостоятельным языком со своей спецификацией — **ECMAScript**.
- JS может выполняться не только в браузере, но и на сервере (Node.js) и других устройствах — везде, где есть специальная программа-«движок» (например, V8 в Chrome, SpiderMonkey в Firefox).

### Что может JS в браузере
- Добавлять и изменять HTML/CSS «на лету».
- Реагировать на действия пользователя (клики, движения мыши, нажатия клавиш).
- Отправлять запросы на сервер, загружать и скачивать файлы (AJAX).
- Работать с cookie, показывать всплывающие окна, сохранять данные локально (localStorage).

### Чего JS не может в браузере (ради безопасности)
- Не может свободно читать/писать файлы на диске или запускать программы — доступ к файлам возможен только через явные действия пользователя (drag-n-drop, `<input>`).
- Не может получить доступ к содержимому другой вкладки/окна, если они с другого домена — это ограничение называется **Same Origin Policy**.
- Ограничен в отправке запросов на другие сайты/домены без явного согласия удалённой стороны.

### Что делает JS особенным
Три сильные стороны, которые редко встречаются вместе у одного языка:
1. Полная интеграция с HTML/CSS.
2. Простые вещи делаются просто.
3. Поддержка всеми основными браузерами «из коробки».

### Языки поверх JavaScript
Так как синтаксис JS подходит не для всех задач, появились языки, которые транспилируются (конвертируются) в JS перед запуском в браузере:
- **CoffeeScript** — более короткий и лаконичный синтаксис.
- **TypeScript** — добавляет строгую типизацию (разработка Microsoft).
- **Flow** — тоже добавляет типизацию (разработка Facebook).
- **Dart** — отдельный язык от Google со своим движком.
- **Brython** — транспилирует Python в JS.

## 2. Справочники и спецификации

### Спецификация
- **Спецификация ECMA-262** — самый точный и формальный источник информации о языке. Тяжело читается, но это эталон.
- Актуальный черновик будущей версии — на tc39.es/ecma262.
- Информацию о новых предложениях («stage 3 proposals») можно найти в репозитории tc39/proposals на GitHub.

### Справочники
- **MDN (Mozilla) JavaScript Reference** — удобный справочник с примерами по функциям языка и встроенным объектам. Часто удобнее искать через поисковик запросом вида «MDN parseInt», чем через сайт напрямую.

### Таблицы совместимости
- **caniuse.com** — поддержка конкретных возможностей разными браузерами.
- **kangax.github.io/compat-table** — таблица возможностей языка и их поддержки движками.

## 3. Редакторы кода

Два основных типа редакторов — многие разработчики используют по одному из каждого типа.

### IDE (интегрированная среда разработки)
Мощные редакторы, работающие на уровне всего проекта: переключение между файлами, автодополнение по всему проекту, интеграция с git и инструментами тестирования.
- **Visual Studio Code** — кроссплатформенный, бесплатный.
- **WebStorm** — кроссплатформенный, бесплатный для некоммерческого использования.
- **Visual Studio** (не путать с VS Code) — платная, только для Windows, хороша для .NET.

### «Лёгкие» редакторы
Менее мощные, но быстрые и простые — удобны, чтобы быстро открыть и отредактировать один файл.
- **Sublime Text** — кроссплатформенный, условно-бесплатный.
- **Notepad++** — только Windows, бесплатный.
- **Vim** и **Emacs** — мощные, но требуют навыка работы с ними.

Выбор редактора — дело индивидуальное, зависит от привычек и задач.

## 4. Консоль разработчика

- По умолчанию браузер не показывает ошибки в коде явно — для этого существуют **инструменты разработчика (DevTools)**.
- Открываются клавишей `F12` (на Mac для Chrome — `Cmd+Opt+J`).
- Во вкладке **Console**:
  - видны ошибки скрипта (обычно красным цветом) со ссылкой на строку кода, где произошла ошибка;
  - есть командная строка (символ `>`), где можно вводить и выполнять JS-код по нажатию `Enter`;
  - `Shift+Enter` — перенос строки для многострочного ввода.
- В Safari (только Mac) сначала нужно включить пункт меню «Разработка» в настройках браузера, затем консоль открывается через `Cmd+Opt+C`.
- В Firefox, Edge и большинстве других браузеров DevTools открываются также по `F12` и работают похожим образом.

## 5. Основы JavaScript

### 5.1 Привет, мир!

- JS-код вставляется в HTML с помощью тега `<script>`:

```html
<script>
  alert('Привет, мир!');
</script>
```

- Атрибуты `type` и `language` у тега `<script>` сегодня не нужны — это пережитки старого HTML.
- Внешний скрипт подключается через атрибут `src`:

```html
<script src="/path/to/script.js"></script>
```

- Плюс вынесения кода в отдельный файл — браузер кэширует его, и при повторных обращениях файл не скачивается заново.
- **Важно:** если у тега `<script>` указан `src`, содержимое внутри тега игнорируется — нельзя одновременно подключать внешний файл и писать код внутри того же тега.

### 5.2 Структура кода

**Инструкции** — это синтаксические конструкции, выполняющие действие (например, `alert('Привет')`). Обычно каждую инструкцию пишут на отдельной строке для читаемости.

**Точка с запятой**
- В большинстве случаев её можно не ставить — перенос строки чаще всего трактуется как автоматическая точка с запятой (ASI).
- Но бывают исключения, когда автоматическая расстановка «не срабатывает» и код может привести к ошибке (например, если следующая строка начинается с квадратной скобки `[`).
- Рекомендация: ставить точку с запятой всегда, даже когда без неё код работает — это общепринятая практика.

**Комментарии**
- Однострочный: `// текст комментария`.
- Многострочный: `/* текст */`.
- Вложенные многострочные комментарии не поддерживаются.
- Комментарии не влияют на выполнение и не увеличивают итоговый размер продакшн-кода — их вырезают минификаторы.

### 5.3 Строгий режим — "use strict"

- До ES5 (2009 год) язык менялся с сохранением полной обратной совместимости — из-за этого некоторые старые ошибки навсегда «застряли» в языке.
- ES5 добавил улучшения, которые по умолчанию отключены (чтобы не сломать старый код) и включаются явной директивой:

```javascript
"use strict";
```

- Директива должна находиться **в самом начале** скрипта или функции — выше могут быть только комментарии, иначе строгий режим не включится.
- Отменить `use strict` после включения нельзя.
- В консоли браузера строгий режим по умолчанию выключен — чтобы включить его там, нужно ввести `'use strict';`, затем `Shift+Enter` и уже дальше — свой код.
- Современные конструкции — **классы** и **модули** — включают строгий режим автоматически, поэтому директива для них не нужна.
- Рекомендация: пока код не состоит целиком из классов/модулей, стоит начинать скрипты с `"use strict"`.

### 5.4 Переменные

- Переменная — «именованное хранилище» для данных. Объявляется ключевым словом `let`:

```javascript
let message;
message = 'Hello';
// или сразу:
let message = 'Hello';
```

- Несколько переменных лучше объявлять на отдельных строках — так код читабельнее (хотя через запятую тоже работает).
- `var` — устаревший аналог `let` из старого кода, между ними есть тонкие различия.
- Значение переменной можно менять сколько угодно раз; при присвоении нового значения старое стирается.
- Повторное объявление переменной через `let` в той же области видимости — ошибка (`SyntaxError`).

**Имена переменных**
- Разрешены буквы, цифры, `$` и `_`; первый символ не может быть цифрой.
- Обычно используется camelCase (`myVeryLongName`).
- Регистр важен: `apple` и `APPLE` — разные переменные.
- Нельзя использовать зарезервированные слова (`let`, `class`, `return`, `function` и т.д.) в качестве имени.
- Без `use strict` можно создать переменную простым присваиванием без `let` — это устаревшая практика, в строгом режиме она вызывает ошибку.

**Константы**
- Объявляются через `const` — значение после присвоения изменить нельзя.
- Константы с «жёстко закодированным» значением, известным заранее, принято называть заглавными буквами с подчёркиванием (`COLOR_RED`); константы, которые вычисляются во время выполнения, пишут обычным регистром.

**Хорошие имена переменных**
- Имя должно ясно отражать содержимое (`userName`, `shoppingCart`), а не быть абстрактным (`data`, `value`).
- Не стоит экономить на количестве переменных ради «удобства» — дополнительная переменная помогает и читаемости, и отладке, а не вредит производительности.

### 5.5 Типы данных

Значение в JS всегда имеет определённый тип, но переменная не привязана к типу — язык **динамически типизированный**. Всего 8 основных типов:

1. **number** — числа, включая дробные, а также специальные значения `Infinity`, `-Infinity` и `NaN` (результат некорректной математической операции). Математические операции в JS «безопасны» — скрипт не «падает», в худшем случае возвращает `NaN`.
2. **bigint** — для целых чисел произвольной длины, выходящих за пределы безопасного диапазона `number` (`±(2^53-1)`). Создаётся добавлением `n` в конце: `1234567890123456789012345678901234567890n`.
3. **string** — строки. Три вида кавычек: двойные и одинарные — равнозначны, обратные (бэктики) — позволяют вставлять выражения через `${...}` (шаблонные строки):

```javascript
let name = "Иван";
alert(`Привет, ${name}!`); // Привет, Иван!
```

4. **boolean** — только `true` и `false`, часто результат сравнений.
5. **null** — специальное значение «пусто» / «неизвестно», отдельный тип.
6. **undefined** — означает «значение не присвоено»; такое значение получает объявленная, но не инициализированная переменная.
7. **object** — единственный не примитивный тип, хранит сложные структуры и коллекции данных.
8. **symbol** — используется для уникальных идентификаторов объектов.

**Оператор `typeof`**
- Возвращает строку с именем типа: `typeof 5` → `"number"`, `typeof "foo"` → `"string"` и т.д.
- Особенности: `typeof null` возвращает `"object"` — это историческая ошибка языка; `typeof alert` (функция) возвращает `"function"`, хотя отдельного типа «функция» в JS нет — функции технически относятся к объектам.

### 5.6 Взаимодействие: alert, prompt, confirm

Три встроенные функции браузера для простого общения с пользователем — все три **модальные** (блокируют работу со страницей, пока окно не закрыто), и их внешний вид задаётся браузером, а не разработчиком.

- **`alert(message)`** — показывает сообщение и ждёт нажатия «ОК».
- **`prompt(title, [default])`** — показывает окно с текстом и полем ввода:
  - `title` — текст сообщения;
  - `default` (необязательный) — значение по умолчанию в поле ввода.
  - Возвращает введённый текст, либо `null`, если пользователь нажал «Отмена» или `Esc`.

```javascript
let age = prompt('Сколько тебе лет?', 100);
alert(`Тебе ${age} лет!`);
```

- **`confirm(question)`** — окно с вопросом и кнопками «ОК»/«Отмена». Возвращает `true` при нажатии «ОК», иначе `false`.

```javascript
let isBoss = confirm("Ты здесь главный?");
alert(isBoss); // true или false
```


# Конспект Основы JavaScript

## 1. Преобразование типов

Операторы и функции автоматически приводят значения к нужному типу. Есть три основных преобразования: **строковое**, **численное** и **логическое**.

### Строковое преобразование

Происходит при выводе значения (`alert`) или вызове `String(value)`.

```js
let value = true;
alert(typeof value); // boolean

value = String(value); // теперь value = "true"
alert(typeof value); // string
```

### Численное преобразование

Происходит в математических операциях и выражениях, а также при вызове `Number(value)`.

```js
alert("6" / "2"); // 3, строки преобразуются в числа

let str = "123";
let num = Number(str); // 123
alert(typeof num); // number

let age = Number("текст"); // NaN — ошибка преобразования
```

Правила преобразования `Number(value)`:

- `undefined` — `NaN`
- `null` — `0`
- `true` / `false` — `1` / `0`
- строка — пробелы по краям удаляются; пустая строка → `0`; иначе число из строки или `NaN` при ошибке

```js
alert(Number("   123   ")); // 123
alert(Number("123z"));      // NaN
alert(Number(true));        // 1
alert(Number(false));       // 0
```

### Логическое преобразование

Происходит в логических операциях, а также при вызове `Boolean(value)`.

- Значения, которые интуитивно «пустые» (`0`, `""`, `null`, `undefined`, `NaN`), становятся `false`.
- Все остальные значения становятся `true`.

```js
alert(Boolean(1));          // true
alert(Boolean(0));          // false
alert(Boolean("привет"));   // true
alert(Boolean(""));         // false
alert(Boolean("0"));        // true (!)
alert(Boolean(" "));        // true (строка с пробелом не пустая)
```

> ⚠️ **Важно:** `"0"` — это `true`, так как непустая строка.

## 2. Базовые операторы, математика



- **Операнд** — то, к чему применяется оператор. В `5 * 2` два операнда: `5` и `2`.
- **Унарный** оператор применяется к одному операнду (`-x`).
- **Бинарный** оператор применяется к двум операндам (`a - b`).

### Математические операторы

- `+` — сложение — `2 + 2 = 4`
- `-` — вычитание — `5 - 3 = 2`
- `*` — умножение — `2 * 3 = 6`
- `/` — деление — `8 / 2 = 4`
- `%` — остаток от деления — `5 % 2 = 1`
- `**` — возведение в степень — `2 ** 3 = 8`

```js
alert(5 % 2);   // 1
alert(8 % 3);   // 2
alert(2 ** 4);  // 16
alert(4 ** (1 / 2)); // 2 (квадратный корень)
```

### Сложение строк через бинарный `+`

Если один из операндов — строка, то другой тоже преобразуется в строку.

```js
alert("1" + 2);    // "12"
alert(2 + "1");    // "21"
alert(2 + 2 + "1"); // "41", а не "221" (выполняется слева направо)
```

Остальные арифметические операторы работают только с числами:

```js
alert(6 - "2"); // 4
alert("6" / "2"); // 3
```

### Унарный плюс

Преобразует значение в число (аналог `Number(...)`).

```js
alert(+true); // 1
alert(+"");   // 0

let apples = "2";
let oranges = "3";
alert(+apples + +oranges); // 5
```

### Приоритет операторов

Чем больше число, тем выше приоритет.

- 15 — унарный `+`, унарный `-`
- 14 — `**`
- 13 — `*`, `/`, `%`
- 12 — `+`, `-`
- 2 — `=` (присваивание)

### Присваивание

Присваивание `=` — тоже оператор, он возвращает значение.

```js
let a = 1;
let b = 2;
let c = 3 - (a = b + 1);

alert(a); // 3
alert(c); // 0

// цепочка присваиваний
let x, y, z;
x = y = z = 2 + 2;
```

### Сокращённая запись

```js
let n = 2;
n += 5;  // n = n + 5  → 7
n *= 2;  // n = n * 2  → 14
```

### Инкремент и декремент

- `++` — увеличивает на 1
- `--` — уменьшает на 1

Работают только с переменными.

```js
let counter = 2;
counter++; // 3
counter--; // 2
```

Префиксная и постфиксная формы:

```js
let a = 1;
alert(++a); // 2 (сначала увеличили, потом вернули)

let b = 1;
alert(b++); // 1 (вернули старое значение, потом увеличили)
```

### Побитовые операторы

Работают с аргументами как с 32-разрядными целыми числами: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`.

### Оператор запятая

Вычисляет все выражения, но возвращает значение **последнего**.

```js
let a = (1 + 2, 3 + 4);
alert(a); // 7
```

## 3. Операторы сравнения

- `>` — больше
- `<` — меньше
- `>=` — больше или равно
- `<=` — меньше или равно
- `==` — равно (нестрогое)
- `===` — строго равно
- `!=` — не равно (нестрогое)
- `!==` — строго не равно

Результат сравнения — значение логического типа (`true` / `false`).

```js
alert(2 > 1);  // true
alert(2 == 1); // false
alert(2 != 1); // true
```

### Сравнение строк

Строки сравниваются посимвольно в «алфавитном» порядке (по кодам Unicode).

```js
alert("Я" > "А");     // true
alert("Кот" > "Код"); // true
alert("Сонный" > "Сон"); // true
alert("a" > "Z");     // true (строчные буквы больше заглавных)
```

### Сравнение разных типов

Значения приводятся к числам.

```js
alert("2" > 1);   // true
alert("01" == 1); // true
alert(true == 1); // true
alert(false == 0); // true
```

### Строгое сравнение `===`

Оператор `==` не различает `0` и `false`, а также `""` и `false`. Оператор `===` **не приводит типы** и сравнивает значения вместе с типом.

```js
alert(0 == false);   // true
alert("" == false);  // true
alert(0 === false);  // false (разные типы)
```

### Сравнение с `null` и `undefined`

```js
alert(null === undefined); // false
alert(null == undefined);  // true (специальное правило)

// при сравнении < > <= >= null → 0, undefined → NaN
alert(null > 0);  // false
alert(null == 0); // false
alert(null >= 0); // true (!)

alert(undefined > 0);  // false (NaN)
alert(undefined == 0); // false
```

> !!! Лучше избегать сравнения `null` и `undefined` с `<`, `>`, `<=`, `>=`. Обрабатывайте их отдельно.

---

## 4. Условное ветвление: if, '?'

### Инструкция `if`

Вычисляет условие в скобках и, если результат `true`, выполняет блок кода.

```js
let year = prompt("В каком году появилась спецификация ECMAScript-2015?", "");

if (year == 2015) alert("Вы правы!");
```

Для нескольких инструкций используют фигурные скобки:

```js
if (year == 2015) {
  alert("Правильно!");
  alert("Вы такой умный!");
}
```

### Преобразование к логическому типу

Условие всегда приводится к `boolean`:

- `0`, `""`, `null`, `undefined`, `NaN` → `false`
- остальное → `true`

```js
if (0) { /* не выполнится */ }
if (1) { /* выполнится */ }
```

### Блок `else`

```js
if (year == 2015) {
  alert("Вы угадали!");
} else {
  alert("Как вы можете так ошибаться?");
}
```

### Несколько условий: `else if`

```js
if (year < 2015) {
  alert("Это слишком рано...");
} else if (year > 2015) {
  alert("Это поздновато");
} else {
  alert("Верно!");
}
```

### Условный оператор `?`

Тернарный оператор — короткая запись `if...else`. Единственный оператор с **тремя** операндами.

```js
let result = условие ? значение1 : значение2;
```

```js
let accessAllowed = age > 18 ? true : false;
// можно проще
let accessAllowed2 = age > 18;
```

### Несколько операторов `?`

```js
let message = age < 3 ? "Здравствуй, малыш!" :
  age < 18 ? "Привет!" :
  age < 100 ? "Здравствуйте!" :
  "Какой необычный возраст!";
```

> 💡 Не стоит использовать `?` вместо `if` для выполнения разных ветвей кода. Оператор `?` предназначен для **присвоения значения** в зависимости от условия.

---

## 5. Логические операторы

В JavaScript есть три логических оператора: `||` (ИЛИ), `&&` (И), `!` (НЕ).

### `||` (ИЛИ)

```js
alert(true || true);   // true
alert(false || true);  // true
alert(true || false);  // true
alert(false || false); // false
```

Если операнд не логического типа, он преобразуется к нему для вычислений.

```js
if (1 || 0) { // сработает как if (true || false)
  alert("truthy!");
}
```

**ИЛИ «||» находит первое истинное значение.**

Цепочка вычисляется слева направо, пока не найдётся «истинное» значение. Если все операнды ложны — возвращается последний.

```js
alert(1 || 0);                   // 1
alert(null || 1);                // 1
alert(null || 0 || 1);           // 1
alert(undefined || null || 0);   // 0 (последнее значение)
```

Применение — значение по умолчанию:

```js
let firstName = "";
let nickName = "Суперкодер";

alert(firstName || nickName || "Аноним"); // Суперкодер
```

**Вычисление по короткому циклу** — правый операнд не вычисляется, если результат уже ясен:

```js
true || alert("не выполнится");
false || alert("выполнится");
```

### `&&` (И)

```js
alert(true && true);   // true
alert(false && true);  // false
alert(true && false);  // false
alert(false && false); // false
```

**И «&&» находит первое ложное значение.**

Если все значения истинные — возвращается последнее.

```js
alert(1 && 0);       // 0
alert(1 && 5);       // 5
alert(null && 5);    // null
alert(1 && 2 && 3);  // 3
```

> Приоритет `&&` **выше**, чем у `||`.

> !!! Не заменяйте `if` на `||` или `&&` — это ухудшает читаемость кода.

### `!` (НЕ)

Преобразует операнд к логическому типу и возвращает **противоположное** значение.

```js
alert(!true);  // false
alert(!0);     // true

// двойное НЕ — аналог Boolean(...)
alert(!!"непустая строка"); // true
alert(!!null);              // false
```

Приоритет `!` — **самый высокий** из всех логических операторов.

---

## 6. Операторы нулевого слияния и присваивания: `??`, `??=`

### Оператор нулевого слияния `??`

Результат `a ?? b`:

- если `a` определено (не `null` и не `undefined`), то `a`;
- иначе `b`.

```js
// аналог без ??
result = (a !== null && a !== undefined) ? a : b;
```

```js
let user;

alert(user ?? "Аноним"); // Аноним

let name = "Катя";
alert(name ?? "Аноним"); // Катя
```

Выбор первого определённого значения из списка:

```js
let firstName = null;
let lastName = null;
let nickName = "Суперкодер";

alert(firstName ?? lastName ?? nickName ?? "Аноним"); // Суперкодер
```

### Сравнение `??` и `||`

- `||` возвращает первое **истинное** значение;
- `??` возвращает первое **определённое** значение (не `null` / `undefined`).

```js
let height = 0;

alert(height || 100); // 100
alert(height ?? 100); // 0
```

`||` не отличает `0`, `""`, `false` от `null` / `undefined`, а `??` — отличает.

### Приоритет

Приоритет `??` низкий (в таблице MDN — 3), чуть выше `?` и `=`. Поэтому при использовании `??` вместе с другими операторами лучше ставить скобки.

```js
let height = null;
let width = null;

let area = (height ?? 100) * (width ?? 50);
alert(area); // 5000
```

### Запрет использования с `||` и `&&` без скобок

```js
// let x = 1 && 2 ?? 3; // Синтаксическая ошибка
let x = (1 && 2) ?? 3;  // Работает
alert(x); // 2
```

### Оператор присваивания нулевого слияния `??=`

Присваивает значение переменной, **только если** она сейчас `null` или `undefined`.

```js
let user = { name: null };

user.name ??= "Аноним";
alert(user.name); // Аноним

user.age = 25;
user.age ??= 18;
alert(user.age); // 25 (не изменилось)
```

## Циклы while и for

Цикл (loop) - конструкция языка, которая позволяет многократно выполнять один и тот же блок кода (тело цикла). Один проход по телу цикла называется итерацией.

### Цикл while

Синтаксис:

```js
while (условие) {
  // код, тело цикла
}
```

- Пока условие после приведения к логическому типу (boolean) истинно (`true`), выполняется тело цикла.
- Любое выражение или переменная может быть условием. Значения `0`, `""`, `null`, `undefined`, `NaN` и `false` приводятся к `false`, всё остальное - к `true`.
- Если тело цикла состоит из одной инструкции, фигурные скобки можно опустить.

Пример:

```js
let i = 0;
while (i < 3) {
  console.log(i); // 0, 1, 2
  i++;
}
```

### Цикл do...while

Проверка условия выполняется после выполнения тела, поэтому тело всегда выполнится хотя бы один раз.

```js
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 3);
```

Применяется, когда тело цикла нужно выполнить минимум один раз независимо от условия.

### Цикл for

Наиболее часто используемый цикл. Синтаксис:

```js
for (начало; условие; шаг) {
  // тело цикла
}
```

- **начало** - выполняется один раз при входе в цикл (обычно объявление счётчика).
- **условие** - проверяется перед каждой итерацией; если ложно, цикл останавливается.
- **тело** - выполняется, пока условие истинно.
- **шаг** - выполняется после тела на каждой итерации.

Пример:

```js
for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}
```

Переменная, объявленная внутри `for` через `let`, видна только внутри цикла (встроенное объявление переменной).

Любую часть заголовка `for` можно пропустить:

```js
let i = 0;
for (; i < 3; i++) {
  console.log(i);
}

// бесконечный цикл
for (;;) {
  // выполняется бесконечно, пока не сработает break
}
```

### Директивы break и continue

- `break` - принудительный выход из цикла.
- `continue` - прекращает выполнение текущей итерации и переходит к следующей. Это "облегчённая версия" `break`: цикл не останавливается, а переходит к следующему шагу.

```js
let sum = 0;
while (true) {
  let value = +prompt("Введите число", "");
  if (!value) break; // выход из цикла
  sum += value;
}

for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue; // пропустить чётные
  console.log(i); // 1, 3, 5, 7, 9
}
```

Важно: директивы `break` и `continue` нельзя использовать справа от оператора `?` (тернарного оператора), так как они не являются выражениями.

### Метки для break и continue

Метка (label) - идентификатор с двоеточием перед циклом. Позволяет выйти сразу из нескольких вложенных циклов.

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer; // выход из обоих циклов
    console.log(i, j);
  }
}
```

Метка должна находиться на цикле, к которому она относится; перейти на произвольное место в коде с помощью метки нельзя.

## Конструкция switch

Конструкция `switch` заменяет собой несколько последовательных `if` и является более наглядным способом сравнить выражение сразу с несколькими вариантами.

Синтаксис:

```js
switch (x) {
  case 'value1':
    // код
    break;

  case 'value2':
    // код
    break;

  default:
    // код по умолчанию
    break;
}
```

Как работает:

- Значение `x` проверяется на строгое равенство (`===`) со значениями из каждого `case` по порядку.
- При совпадении выполняется код, начиная с соответствующего `case`, до ближайшего `break` (или до конца `switch`).
- Если совпадений нет, выполняется код ветки `default` (если она есть).
- Если `break` отсутствует, выполнение продолжится в следующем `case` без проверок. Это называется "проваливанием" (fall-through).

Пример:

```js
let a = 2 + 2;

switch (a) {
  case 3:
    console.log('Маловато');
    break;
  case 4:
    console.log('В точку!');
    break;
  case 5:
    console.log('Перебор');
    break;
  default:
    console.log('Нет таких значений');
}
```

### Группировка case

Несколько вариантов `case`, использующих один и тот же код, можно сгруппировать:

```js
let a = 3;

switch (a) {
  case 4:
    console.log('Правильно!');
    break;

  case 3: // оба case выполняют один код
  case 5:
    console.log('Неправильно!');
    console.log('Может, пойти на урок математики?');
    break;

  default:
    console.log('Результат странный.');
}
```

### Тип имеет значение

Сравнение в `switch` строгое: значения должны быть одного типа. Например, строка `"3"` не совпадёт с числом `3`.

## Функции

Функция (function) - именованный блок кода, который можно вызывать многократно. Функции являются основными "строительными блоками" программы и помогают избежать дублирования кода.

### Объявление функции (Function Declaration)

```js
function showMessage() {
  console.log('Всем привет!');
}

showMessage(); // вызов функции
```

Ключевое слово `function` идёт первым, затем имя функции, затем список параметров в круглых скобках и тело функции в фигурных скобках.

### Локальные переменные

Переменная, объявленная внутри функции, видна только внутри этой функции.

```js
function showMessage() {
  let message = "Привет, я JavaScript!"; // локальная переменная
  console.log(message);
}

showMessage();
console.log(message); // ошибка: переменная message недоступна снаружи
```

### Внешние переменные

Функция может обращаться к внешним переменным и изменять их. Если внутри функции объявлена переменная с тем же именем, она затеняет (shadows) внешнюю.

```js
let userName = 'Вася';

function showMessage() {
  let message = 'Привет, ' + userName;
  console.log(message);
}

showMessage(); // Привет, Вася
```

Рекомендуется минимизировать использование глобальных переменных: код становится более понятным и менее подверженным ошибкам, если функция получает данные через параметры.

### Параметры (аргументы)

Параметр (parameter) - переменная в объявлении функции. Аргумент (argument) - значение, которое передаётся функции при вызове.

```js
function showMessage(from, text) {
  console.log(from + ': ' + text);
}

showMessage('Аня', 'Привет!'); // Аня: Привет!
showMessage('Аня', 'Как дела?'); // Аня: Как дела?
```

Значения передаются в функцию копированием, поэтому изменение параметра внутри функции не влияет на внешнюю переменную.

### Значения по умолчанию

Если аргумент не передан, соответствующий параметр становится равным `undefined`. Значение по умолчанию задаётся через `=`:

```js
function showMessage(from, text = "текст не добавлен") {
  console.log(from + ": " + text);
}

showMessage("Аня"); // Аня: текст не добавлен
```

Значение по умолчанию может быть и более сложным выражением, в том числе вызовом другой функции. Оно вычисляется каждый раз при вызове, если параметр не передан.

### Возврат значения

Функция может вернуть результат в вызывающий код с помощью директивы `return`.

```js
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
console.log(result); // 3
```

- После `return` выполнение функции немедленно прекращается.
- Директив `return` в функции может быть несколько (например, в разных ветках `if`).
- `return` без значения, а также функция без `return`, возвращают `undefined`.
- Нельзя добавлять перевод строки между `return` и возвращаемым значением: JavaScript автоматически подставит точку с запятой после `return`.

```js
function checkAge(age) {
  if (age >= 18) {
    return true;
  }
  return false;
}
```

### Выбор имени функции

Функция - это действие, поэтому её имя обычно является глаголом. Имя должно кратко и точно описывать, что делает функция. Распространены префиксы:

- `show...` - что-то показывает;
- `get...` - возвращает значение;
- `calc...` - что-то вычисляет;
- `create...` - что-то создаёт;
- `check...` - что-то проверяет и возвращает логическое значение.

Одна функция - одно действие. Если нужно выполнить несколько действий, лучше разбить их на отдельные функции.

---

## Function Expression

В JavaScript функция является особым видом значения, а не особой языковой структурой. Поэтому её можно создать как выражение и присвоить переменной.

### Синтаксис

```js
let sayHi = function() {
  console.log("Привет");
};
```

Здесь функция создаётся и явно присваивается переменной, как любое другое значение. Точка с запятой в конце нужна, так как это обычное присваивание.

Функцию можно скопировать в другую переменную и вывести её код как строку:

```js
function sayHi() {
  console.log("Привет");
}

let func = sayHi; // копируем функцию (без скобок!)
func(); // Привет
sayHi(); // Привет

console.log(sayHi); // выведет код функции, но не вызовет её
```

Скобки `()` нужны для вызова. Без скобок происходит обращение к самой функции как к значению.

### Функции-колбэки (callback)

Колбэк - функция, которая передаётся в другую функцию как аргумент и вызывается позже ("обратный вызов").

```js
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

ask(
  "Вы согласны?",
  function() { console.log("Вы согласились."); },
  function() { console.log("Вы отменили выполнение."); }
);
```

Функции `yes` и `no` здесь - анонимные функции, то есть функции без имени.

### Function Expression и Function Declaration: различия

1. **Момент создания.** Function Expression создаётся, когда выполнение доходит до него. Function Declaration обрабатывается заранее, ещё до выполнения кода.

```js
sayHi("Вася"); // работает: Function Declaration доступна до своего объявления

function sayHi(name) {
  console.log(`Привет, ${name}`);
}
```

```js
sayHi("Вася"); // ошибка: функция ещё не создана

let sayHi = function(name) {
  console.log(`Привет, ${name}`);
};
```

2. **Область видимости.** В строгом режиме Function Declaration внутри блока кода (`if`, цикл и т. д.) видна только внутри этого блока. Для доступа снаружи можно объявить переменную до блока и присвоить ей Function Expression внутри блока.

```js
let welcome;

if (age < 18) {
  welcome = function() { console.log("Привет!"); };
} else {
  welcome = function() { console.log("Здравствуйте!"); };
}

welcome();
```

Рекомендация: сначала стоит рассматривать синтаксис Function Declaration. Он даёт больше свободы в организации кода, поскольку функции можно вызывать до их объявления.

---

## Стрелочные функции, основы

Стрелочные функции (arrow functions) - более короткий синтаксис создания функций, часто более удобный, чем Function Expression.

### Синтаксис

```js
let func = (arg1, arg2, ..., argN) => expression;
```

Это эквивалентно:

```js
let func = function(arg1, arg2, ..., argN) {
  return expression;
};
```

Пример:

```js
let sum = (a, b) => a + b;

console.log(sum(1, 2)); // 3
```

### Особенности записи

- Если аргумент только один, круглые скобки вокруг него можно опустить:

```js
let double = n => n * 2;
console.log(double(3)); // 6
```

- Если аргументов нет, скобки должны быть пустыми, но обязательными:

```js
let sayHi = () => console.log("Привет!");
sayHi();
```

- Стрелочные функции можно использовать так же, как Function Expression, например, для динамического создания функции:

```js
let age = 16;

let welcome = (age < 18) ?
  () => console.log('Привет') :
  () => console.log("Здравствуйте!");

welcome();
```

### Многострочные стрелочные функции

Если требуется несколько инструкций, их нужно заключить в фигурные скобки. В этом случае необходимо явно использовать `return`.

```js
let sum = (a, b) => {
  let result = a + b;
  return result; // при фигурных скобках нужен явный return
};

console.log(sum(1, 2)); // 3
```

### Использование в колбэках

Стрелочные функции удобны для коротких действий, особенно при передаче колбэков:

```js
ask(
  "Вы согласны?",
  () => console.log("Вы согласились."),
  () => console.log("Вы отменили выполнение.")
);
```

Позднее будет показано, что у стрелочных функций есть и другие отличия: они не имеют собственного `this` и объекта `arguments`, а также не могут использоваться как конструкторы с оператором `new`.

## Особенности JavaScript

Краткое повторение основных возможностей языка, изученных в этой части.

### Структура кода

- Инструкции разделяются точкой с запятой. Она может быть пропущена при переводе строки, но рекомендуется всегда её ставить.
- Блоки кода заключаются в фигурные скобки.
- Комментарии бывают однострочные (`// ...`) и многострочные (`/* ... */`).

### Строгий режим

Чтобы включить все возможности современного стандарта, код начинают с директивы `"use strict"`. Современные возможности языка (классы и модули) автоматически включают строгий режим.

```js
"use strict";
```

### Переменные

Объявляются с помощью:

- `let` - переменная с блочной областью видимости;
- `const` - константа, значение которой нельзя переназначить;
- `var` - устаревший способ объявления с функциональной областью видимости.

Язык использует динамическую типизацию: тип хранится в значении, а не в переменной, и один и тот же переменной можно присвоить значения разных типов.

### Типы данных

- `number` - числа (целые и дробные), включая `NaN` и `Infinity`;
- `bigint` - целые числа произвольной длины;
- `string` - строки;
- `boolean` - логические значения `true` и `false`;
- `null` - специальное значение "пусто";
- `undefined` - значение "не присвоено";
- `symbol` - уникальные идентификаторы;
- `object` - объекты и более сложные структуры.

Оператор `typeof` возвращает тип значения. У него есть две особенности: `typeof null` возвращает `"object"` (историческая ошибка языка), а `typeof function(){}` возвращает `"function"`.

### Преобразование типов

- Строковое: `String(value)`, а также происходит при выводе через `alert`.
- Численное: `Number(value)`, а также происходит в математических операциях (кроме бинарного `+` со строкой).
- Логическое: `Boolean(value)`. Значения `0`, `""`, `null`, `undefined`, `NaN` дают `false`.

### Операторы

- Арифметические: `+ - * / % **`. Бинарный `+` при наличии строки выполняет конкатенацию.
- Присваивание: `=` и составные формы `+=`, `*=` и другие. Присваивание возвращает значение.
- Инкремент и декремент: `++`, `--` (префиксная и постфиксная формы).
- Побитовые операторы работают с 32-битными целыми числами.
- Сравнение: `==` (нестрогое, с приведением типов), `===` (строгое), `!=`, `!==`, `<`, `>`, `<=`, `>=`. Значения `null` и `undefined` равны друг другу при нестрогом сравнении, но не равны ничему другому.
- Логические: `||` (ИЛИ), `&&` (И), `!` (НЕ), `??` (оператор нулевого слияния, nullish coalescing).
- Условный (тернарный) оператор: `условие ? значение1 : значение2`.
- Опциональная цепочка `?.` безопасно обращается к свойствам, возвращая `undefined`, если промежуточное значение равно `null` или `undefined`.

```js
let user = null;
console.log(user?.name); // undefined, без ошибки

let name = null;
console.log(name ?? "Аноним"); // Аноним
```

### Условные конструкции и циклы

```js
if (условие) {
  // ...
} else if (другое) {
  // ...
} else {
  // ...
}

for (let i = 0; i < 5; i++) { /* ... */ }
while (условие) { /* ... */ }
do { /* ... */ } while (условие);
```

- Переменная, объявленная в заголовке `for (let ...)`, видна только внутри цикла.
- Директивы `break` и `continue` управляют ходом выполнения, метки позволяют выйти из вложенных циклов.

### Функции

Три способа создания:

```js
// 1. Function Declaration
function sum(a, b) {
  return a + b;
}

// 2. Function Expression
let sum = function(a, b) {
  return a + b;
};

// 3. Стрелочная функция
let sum = (a, b) => a + b;
```

- У функций могут быть локальные переменные, видимые только внутри тела функции.
- Параметры могут иметь значения по умолчанию: `function sum(a = 1, b = 2) {}`.
- Функция всегда что-то возвращает: если `return` не указан, возвращается `undefined`.

### Основное различие Declaration и Expression

**Function Declaration:**

- доступна для вызова до места объявления в коде;
- создаётся заранее, при обработке скрипта;
- подходит для основных именованных функций.

**Function Expression:**

- недоступна до места объявления в коде;
- создаётся, когда выполнение доходит до выражения;
- подходит для колбэков и присваивания в переменные.
