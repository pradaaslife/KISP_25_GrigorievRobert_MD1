## 2. Жизненный цикл проекта (Разделы меню)

### Develop (Разработка):
 Инструменты разработки, навигация, пользовательский интерфейс, сборки для разработки (Development builds), конфигурационные плагины (Config plugins), отладка (Debugging), базы данных, авторизация и юнит-тестирование.

### Review (Обзор и проверка): 
Распределение приложений для проверки, организация совместного доступа к превью-версиям внутри команды, а также запуск обновлений с помощью утилиты Orbit

### Deploy (Развертывание):
 Сборка проектов для магазинов приложений, отправка (сабмит) в сторы, управление метаданными приложений, отправка мгновенных обновлений «по воздуху» (Over-the-air updates) и деплой веб-приложений. -->

### Monitor (Мониторинг): 
Сервисы непрерывного отслеживания и мониторинга работающего приложения

## 4. Технологические возможности и SDK

 Единый проект: Написание одного кроссплатформенного проекта на JavaScript/TypeScript, работающего на Android, iOS и Web-платформах.

 Zero Config: Модуль Launch позволяет отправлять приложения в магазины напрямую из GitHub без опыта предварительной настройки нативной конфигурации.

 Маршрутизация: Продукт Expo Router реализует файловую навигацию (file-based routing).

 Компоненты SDK: Выделены три базовых нативных модуля: Image (изображения), Camera (камера) и Notifications (уведомления).

 Песочница: Инструмент Expo Snack для тестирования кода прямо в браузере без локальной настройки окружения.

## 5. Консольные команды (CLI) и автоматизация

### ````npx create-expo-app@latest```` 
— Инициализация и создание нового чистого проекта.

### ````npx testflight```` 
— Эксклюзивная команда для iOS-платформы, загружающая приложение в TestFlight.

### ````npx eas-cli deploy```` 
— Команда для развертывания веб-версии приложения.

### EAS Workflows: 
Сервис для создания автоматизированных CI/CD цепочек сборки и релизов.
